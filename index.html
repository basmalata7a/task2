المقدمة

أصبحت صفحات الويب جزءًا مهمًا من حياتنا اليومية، ونستخدمها في التعلم والعمل والتواصل. ولكي تظهر صفحات الويب بشكل منظم وجميل، نحتاج إلى استخدام CSS.

ما هو CSS؟

CSS هي اختصار لـ Cascading Style Sheets، وهي لغة تستخدم لتنسيق صفحات الويب والتحكم في شكل العناصر، مثل الألوان والخطوط والمسافات والخلفيات.

أهمية CSS

  • تغيير ألوان النصوص والخلفيات.
  • تحديد حجم ونوع الخط.
  • تنظيم العناصر داخل الصفحة.
  • جعل الصفحة مناسبة للشاشات المختلفة.

الفرق بين HTML و CSS

HTML CSS
تستخدم لبناء محتوى الصفحة. تستخدم لتنسيق شكل الصفحة.
